# GOOFIES — Next.js Landing Page

## Run
npm install
npm run dev

Open http://localhost:3000

## Edit members
Edit `owners`, `admins`, and `members` in `app/page.js`.

Each person has `name`, `username`, `image`, and `link`. Clicking the card/name goes directly to the account.

## Add media
Put these files in `public/`:
- `music.mp3`
- `goofies.mp4`
- optional `video-poster.svg` or replace it with your own poster

The included SVG avatar files are placeholders. Replace them with your real photos, keeping the filenames or updating `page.js`.

## Publish
Push to GitHub and import the repository into Vercel.
